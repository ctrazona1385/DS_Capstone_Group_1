HPSA Need Classification

This ML model predicts if a non-HPSA-designated tract would qualify as "High Need" (score ≥ 14) if formally evaluated.

Inputs & Features

Uninsured rate, no-checkup rate, median income, poverty rate, and PCP density per 100k population.

Model Design

We utilized a GroupShuffleSplit by county to prevent data leakage and addressed a 1:7.7 class imbalance using SMOTE and XGBoost with Optuna tuning.
