Care Optimize

A Data-Driven DPC Clinic Siting Model
DSCI 4350 - Spring 2026 | Trazona, Finn, Moore, McGee

Executive Summary

Care Optimize identifies optimal locations for Direct Primary Care (DPC) clinic placement across U.S. counties. By balancing community need against financial viability, the model produces Go/No-Go recommendations to address primary care "deserts" and physician maldistribution.

Data Pipeline & Engineering

The pipeline processes raw government data into a merged file of 71,507 tracts using zero-padded FIPS codes as join keys.

NotebookDescription
census_data_call.ipynbPulls ACS 5-year county estimates via Census API
CDC_tract_imputation.ipynbImputes missing BP and cholesterol at tract level
data_merging.ipynbLeft-joins all sources (71,507 tracts, 20 columns)
Financial_Modeling.ipynbProcesses GSA lease data and revenue projections

Data Sources

  • Census ACS: Uninsured rates and demographics.
  • Census SAIPE: Poverty and median income (preferred for small geographies).
  • HRSA AHRF: Primary care provider (PCP) counts.
  • CDC PLACES: Chronic disease prevalence (Diabetes, BP, etc.).
